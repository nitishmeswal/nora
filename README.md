# NORACORP

A scroll-driven 3D cinematic website experience. Built with Next.js 16, Three.js, GSAP, and Lenis.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Next.js 16** + React 19 + TypeScript
- **Three.js** + React Three Fiber + drei — 3D planet & atmosphere shader
- **GSAP** + ScrollTrigger — scroll-driven animations
- **Lenis** — smooth scroll
- **Tailwind CSS v4** — styling
- **Framer Motion** — UI transitions

## Features

1. Circular loader → morphs into 3D planet
2. Interactive scroll-driven planet rotation
3. Planet settles to bottom-right (desktop) / center (mobile)
4. Glitchy text reveal content sections
5. iPhone notch-style navbar with hover dropdown
6. Glass card UI with hover effects
